# 方案 C 渐进与帮派照片墙

## 流程基准

- 以 `dobe-story-blueprint/?plan=C&v=3414e2f` 的最新版 43 循环、7 幕流程为准；主线演出约 75 分钟，后续留作玩法缓冲。
- L01–L08 完成甩警、帮派接应、反伏击、灰狐维修并加装氮气、真正 1v1、首次查看帮派照片墙，以及 Full Patch 转正会议。
- L09 建筑爆炸后，由会长发布全员任务；L10–L16 依次完成收车、批量拆解、三车强化、情报确认、伏击枪战、共同返城与任务提交。
- L17 晋升 Enforcer 并接取内鬼调查；L18 开启产业管理线（L19–L21）和内鬼调查线（L22–L24），两条可任选先后，全部完成后才开放 L25。
- L26–L30 是独立的科腾绑架章节：绑走 Merrill、推关营救、取得路线、SUP 追杀科腾，最终晋升 Road Captain。
- L31–L43 依次恢复商业街、加油站与物流中心经营，完成武装队长、资深成员、副会长和会长职责。
- 金发骑手博始终存活并与玩家共同返城，不再出现牺牲或追悼路线。

## 声望与晋升

- 十层声望门槛固定为：`0 / 100 / 300 / 650 / 1100 / 1700 / 2400 / 3200 / 4200 / 5500`。
- 晋升节点固定为 L08、L17、L25、L30、L35、L38、L39、L41、L43；进入节点前必须达到对应门槛。
- 关键晋升衔接评定会议；首次会议不评上轮任务，后续会议先展示 Thomas 固定 S、NPC 伪随机 A/B/C/D 的完成度。
- L09 是爆炸后的全员行动发布，不是额外晋升会议。

## 照片墙与 N-1

- 照片墙从 T10 到 T1 纵向排列，每层保留 1–5 个照片位置，未使用的位置明确显示空席。
- 玩家位于 N 层时，只可承接 N-1 层的人物、职责和奖励；原成员照片永久保留，不被 Thomas 覆盖。
- L19 是当前方案的显式剧情例外：同一节点需要依次点击 T1 的 Hugo 与 T2 的 Walter 两张照片，全部点亮后才继续；这用于补做修车厂职责并同步废车厂职责，不自动归档。
- L33 的 Spencer、L36 的物流负责人也必须由玩家显式点击照片完成交接。
- 城市和产业始终属于帮派，文案统一使用“内部交接、接管管理职责”，不描述为征服城市或夺取产业所有权。

## 系统与玩法映射

- L20 的修车厂和废车回收厂可任意顺序接管，两座都完成才推进 L21。
- 物流中心继续复用内部建筑 ID `metalworking-plant`，玩家可见名称统一为物流中心，职责是仓储与材料运输。
- Thomas 是剧情和管理身份，不进入推关编队；L22 获得 Maeve 协助，L23 首次由英雄带队推关。
- SUP 关卡按剧情重新排序：L01 警匪竞速、L03 伏击枪战、L06 真 1v1、L14 回程伏击、L24 挡风玻璃审讯、L29 科腾追杀、L38 友好枪战、L39/L42 物资护送、L40 Hank 护送、L41 副会长传统赛。
- 前三次定制化 3D 车辆操作分别为：L05 灰狐维修与氮气加装、L11 两车批量拆解、L12 三辆成员车辆强化。

## 存档迁移

- 最新方案 C 使用独立存档键 `dobe-story-plan-c-v3`。
- 旧版 42/44 节点无法安全映射到新的强制链，因此本版本从 L01 开始，避免旧存档跳过爆炸任务、并行双线或绑架章节。
