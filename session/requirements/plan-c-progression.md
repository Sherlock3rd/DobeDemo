# 方案 C 渐进与帮派照片墙

## 流程基准

- 以 `dobe-story-blueprint/?plan=C&v=6eac08e9` 的 42 个节点、6 幕和 90 分钟流程为准。
- 前 10 节形成完整见习循环：警匪追逐、帮派接应、黑手党伏击、任务板、首次收车拆解、安装氮气、1v1 终考、提交任务、点击晋升和转正会议。
- L11–L20 围绕改装厂遇袭、紧急修复、N-1 收复 Hugo、拆车换件、复仇伏击、Bo 牺牲和打手晋升。
- L21 起按废车回收厂、商业街、加油站、物流中心依次扩展产业，再进入武装队长、资深成员、副会长和会长职责。

## 声望与晋升

- 十层声望门槛固定为：`0 / 100 / 300 / 650 / 1100 / 1700 / 2400 / 3200 / 4200 / 5500`。
- 玩法节点发放声望；达到门槛后必须由玩家在照片墙点击晋升。
- 关键晋升衔接评定会议；首次会议不评上轮任务，后续会议先展示 Thomas 固定 S、NPC 伪随机 A/B/C/D 的完成度。

## 照片墙与 N-1

- 照片墙从 T10 到 T1 纵向排列，每层保留 1–5 个照片位置，未使用的位置明确显示空席。
- 每张照片绑定人物任务和奖励标签，至少覆盖英雄、建筑管理者、经营者；车辆、枪械、声望、零件、金钱、汽油、物资按奖励补充标签。
- 玩家位于 N 层时，只可收复 N-1 层的人物与奖励；原成员照片永久保留，不被 Thomas 覆盖。
- 城市和产业始终属于帮派，文案使用“收复人物/管理线”和“内部管理权”，不描述为夺取城市所有权。

## 系统映射

- 物流中心继续复用内部建筑 ID `metalworking-plant`，但玩家可见名称和职责统一为物流、仓储、材料运输。
- Thomas 是剧情和管理身份，不进入推关编队；L23 解锁 Maeve，L24 首次由 Maeve 带队推关。
- 方案 C 使用独立存档键，避免旧方案 B 的完成节点直接跨过新的强制点击链。
