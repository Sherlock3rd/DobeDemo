# 方案 C 渐进与帮派照片墙

## 流程基准

- 以 `dobe-story-blueprint/?plan=C&v=7ed27f5` 的最新版 44 节点、7 幕和 90 分钟流程为准。
- L01–L08 完成甩警、帮派接应、反伏击、修车装氮气、1v1 庆祝赛、帮派树首次展示与议会转正。
- L09–L19 串联改装厂交接、Hugo 收复、全员任务、收车/拆车/全员强化、与金发共同伏击返城，以及同一会议中的 Enforcer 晋升和内奸调查发布。
- L17 金发小哥存活并与玩家一起返城；不得再播放牺牲或追悼路线。
- L20 开启产业管理线（L21–L23）和内奸调查线（L24–L26）。玩家可任选一条先做，第一条完成后自动切换另一条；两条全部完成后才开放 L27。
- L28–L31 为独立章节：营救梅丽尔、取得科腾去向、追杀科腾、章节结算与 Road Captain 晋升。
- L32–L44 依次恢复商业街、加油站、物流中心，完成武装队长、元老、副会长和会长职责。

## 声望与晋升

- 十层声望门槛固定为：`0 / 100 / 300 / 650 / 1100 / 1700 / 2400 / 3200 / 4200 / 5500`。
- 晋升节点固定为 L08、L19、L27、L31、L36、L39、L40、L42、L44；进入节点前必须已达到对应门槛。
- 关键晋升衔接评定会议；首次会议不评上轮任务，后续会议先展示 Thomas 固定 S、NPC 伪随机 A/B/C/D 的完成度。

## 照片墙与 N-1

- 照片墙从 T10 到 T1 纵向排列，每层保留 1–5 个照片位置，未使用的位置明确显示空席。
- 玩家位于 N 层时，只可收复 N-1 层的人物与奖励；原成员照片永久保留，不被 Thomas 覆盖。
- L10 收复 Hugo、L21 收复 Walter、L34 收复 Spencer、L37 收复物流负责人，均要求玩家显式点击照片后再继续。
- 城市和产业始终属于帮派，文案使用“收复人物/管理线”和“内部管理权”，不描述为夺取城市所有权。

## 系统映射与存档

- L22 的改装厂和废车回收厂可任意顺序接管，两座都完成才推进 L23。
- 物流中心继续复用内部建筑 ID `metalworking-plant`，玩家可见名称和职责统一为物流、仓储、材料运输。
- Thomas 是剧情和管理身份，不进入推关编队；L24 收复 Maeve，L25 首次由 Maeve 带队推关。
- 最新方案 C 使用独立存档键 `dobe-story-plan-c-v2`。旧版 42 节点无法安全映射到新强制链，因此新版本从 L01 开始，避免跳过双线与新章节。
