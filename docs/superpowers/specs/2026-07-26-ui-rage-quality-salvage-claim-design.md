# HUD、怒气技能、五品质与配件领取设计

## 状态

- 用户已批准本设计。
- 本设计替代英雄技能“纯冷却自动释放”、四品质配件和配件自动入库规则。
- 交付后提交 `main`，重新发布并复验 GitHub Pages。

## 目标

1. 消除主 HUD 总战力孤立成行和英雄页战力遮挡。
2. 为英雄主动技能增加真实怒气发动机制与完整说明。
3. 将配件扩展为标准五品质，并安全迁移线上四品质存档。
4. 将配件挂机改为废车回收厂“生产”Tab 手动领取，并展示本次领取结果。

## HUD 与英雄页

采用视觉方案 B：

- 主 HUD 第一行保留英雄头像与帮派按钮。
- 总战力并入帮派按钮，显示 `Lv.N 职位 · 战力 P`。
- 钱、油、物资继续使用独立三格资源条；不再渲染单独战力行。
- 英雄页将英雄战力移到姓名行右侧。
- 立绘容器裁剪溢出；手机端武器不再使用侵入右侧信息区的负偏移。
- 技能名称区域升级为技能卡，展示效果说明、倍率、当前属性预估伤害、怒气消耗与怒气来源。

## 真实怒气技能

### 规则

- 玩家英雄初始怒气为 0，上限 100。
- 每次普攻命中后获得 20 怒气。
- 每次受到一次伤害事件后获得 10 怒气；同一 tick 的多次命中分别计算。
- 轮到英雄行动且怒气达到 100 时，自动释放主动技能。
- 技能释放后怒气清空为 0。
- 玩家英雄不再用冷却决定主动技能释放。
- 敌方单位继续使用现有冷却技能模型，避免改变敌方关卡平衡。
- 同一输入必须继续得到相同战斗结果。

### 配置与快照

英雄技能配置增加：

- `description`：效果说明。
- `rageCost`：固定为 100。
- `ragePerBasicAttack`：固定为 20。
- `ragePerHitTaken`：固定为 10。

玩家战斗单位状态增加 `rage` 与 `maxRage`。Battle HUD 对玩家显示怒气条；敌方内部冷却字段继续保留。HeroesPanel 根据当前英雄 ATK、技能倍率和伤害公式展示主目标与溅射预估伤害。

### 旧档迁移

Adventure persist 从 v5 升至 v6，存储键不变：

- `worn` → `common`
- `tuned` → `rare`
- `elite` → `epic`
- `prototype` → `legendary`

迁移必须保留配件 ID、部位、等级和安装关系。`uncommon` 只从新掉落产生。未知品质仍被拒绝，但合法旧品质必须先映射再校验。

## 配件挂机手动领取

### 数据模型

继续复用现有持久字段：

- `partIdleClock`：上次领取或首次解锁的时间。
- `nextPartSerial`：下一配件序号。
- `carPartInventory`：配件仓库。
- `spareParts`：满仓自动回收所得零件。

不持久化预生成配件。挂机期间只根据 `partIdleClock`、当前时间和回收厂等级计算只读预览；点击领取时才调用真随机生成配件。

### API

新增只读预览，返回：

- 累计毫秒数（最多 8 小时）。
- 已完成批次数。
- 当前批进度与下一批剩余时间。
- 是否可领取。
- 是否达到 8 小时上限。

新增 `claimPartSalvage(now, recyclingYardLevel, random?)`，返回：

- 是否领取成功。
- 本次入库配件列表。
- 本次自动回收件数。
- 本次自动回收获得的零件。
- 本次结算批次数。

领取成功后更新库存、零件、序号和时钟。仓库上限仍为 40；溢出配件按品质回收基值自动转为零件。达到 8 小时上限后领取将时钟推进到当前时间，避免反复显示过期累计时间。

### Controller

`PartSalvageController` 不再每秒自动调用结算写入库存，只保留“首次解锁时重置时钟，不追溯解锁前时间”的职责。界面倒计时由已有 UI tick 驱动，不产生 Store 写入。

## 废车回收厂面板

- 只有废车回收厂显示“建筑 / 生产”Tab。
- 每次打开默认进入“建筑”Tab。
- 有完整批次可领取时，“生产”Tab 显示红点和批次数。
- 建筑 Tab 保留子建筑、主建筑升级和施工队列。
- 生产 Tab 展示累计时间、已完成批次、当前批进度、下一批倒计时、仓库容量与 8 小时上限。
- 未完成一批时领取按钮禁用；可领取时显示“领取 N 批”。
- 领取成功后打开结果弹窗，逐件展示部位、品质颜色、名称与 Lv.1。
- 满仓自动回收时，弹窗显示自动回收件数和获得零件。
- 关闭结果弹窗后返回生产 Tab。
- 其他建筑不显示 Tab。
- HeroesPanel 移除回收厂倒计时条，保留仓库、装备、强化与五品质批量回收。

## 错误与边界

- 帮派 Lv.8 前不允许领取，也不累计解锁前时间。
- 非法时间、非法回收厂等级或不足一批返回未领取，不修改 Store。
- 领取按钮需要防重复点击；同一次渲染结果只结算一次。
- 刷新和离线不自动入库，重新打开生产 Tab 后恢复累计时间。
- 品质权重必须有限、非负、总和大于 0；随机值仍限定 `[0, 1)`。
- 旧存档迁移不得静默丢弃合法四品质配件。
