# 章节引导、完成奖励与竞速时长调整

## 目标

本轮把章节任务从静态清单改为可执行的成长引导，同时收紧帮派经验投放，并把竞速关卡调整为约一分钟的长路线体验。

## 章节任务引导

每条章节任务增加独立“前往”按钮：

- 英雄等级任务进入英雄培养的等级页。
- 配件等级任务进入英雄培养的车辆/配件页。
- 枪械等级任务进入英雄培养的枪械页。
- 城建任务关闭章节面板并选中指定城市建筑。
- 推关与赛车任务分别进入对应玩法大厅。

任务领取按钮与导航按钮相互独立；已完成或已领取任务仍允许再次前往对应系统。

## 帮派经验与章节完成奖励

帮派经验不再通过在线或离线挂机产生。来源收敛为章节单项任务与章节完成奖励：

- 第一至第五章每项任务 20 帮派经验。
- 第六、七章每项任务 25 帮派经验。
- 前六章“任务总和 + 章节完成奖励”继续精确覆盖当前职级到下一职级的晋升区间。

每章全部任务达成后出现可领取状态，玩家必须点击独立“领取章节奖励”按钮。奖励包括帮派经验、英雄经验、零件、钱/油/物资和高品质配件。跨职级晋升要求该章完成奖励已经领取。

以下装备从帮派树迁移至章节完成奖励：

| 章节 | 装备 |
| --- | --- |
| 第一章 | 铁獠装甲车 |
| 第三章 | 工业卡宾枪 |
| 第五章 | 黑色王座 |

旧版本中已经达到原帮派树解锁等级的存档，会在一次性迁移时保留这些装备的拥有权；新存档必须领取对应章节奖励。

## 英雄技能文案

英雄培养页只展示技能名、简短效果描述和“满怒自动释放”。不展示倍率、怒气获取拆解或预计/理论伤害。战斗计算与技能配置数值不变。

## 竞速关卡

- 五个竞速关路线距离统一增加 50%，依次为 4650、5100、5550、5925、6300 米。
- 竞速模式取消倒计时与超时失败，只在顶部显示紧凑的终点百分比进度条。
- 追击模式继续保留倒计时和超时失败。
- 竞速最快通关体验目标约一分钟。

## 持久化

- 章节存档增加已领取章节编号，保证完成奖励幂等。
- 英雄/装备存档增加章节解锁车辆、枪械与一次性迁移版本。
- 城市奖励使用稳定的 `chapter:<章节号>` 奖励 ID，防止资源重复发放。
